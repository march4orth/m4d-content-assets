# m4d-content-assets

Post-ready Instagram assets for [@march4orthdesign](https://instagram.com/march4orthdesign).

Rendered PNGs and MP4s only — synced from the private `m4d-projects` repo by `scripts/sync-content-assets.sh`. Served to the Instagram Content Publishing API via `raw.githubusercontent.com` URLs.

Do not edit files here directly. Source lives in `m4d-projects/content/social/`.
